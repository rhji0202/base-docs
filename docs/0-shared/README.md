# 0-shared — 전역 공통 설계

여러 기능이 공유하는, **한 기능에 속하지 않는** 프로젝트 전역 설계의 집입니다.
`1-feat` / `2-web` / `3-api`는 **단계**지만, `0-shared`는 단계가 아니라 **모든 단계가 참조하는 기반**입니다 (그래서 `0-`).

## 원칙
- 기능 문서는 공통 사항을 **반복 기술하지 말고 여기로 링크**한다 (DRY).
- 기능 문서에는 그 기능만의 **예외/추가**만 적는다.
