# 사용자 로그인

> **한 줄:** 사용자가 이메일과 비밀번호로 안전하게 로그인할 수 있게 한다.

## 사용자 시나리오
- **일반 사용자**: 이메일/비밀번호로 로그인하고 싶다. 내 정보에 접근하기 위해.

## 핵심 요구사항 (MVP)
- [ ] 이메일 + 비밀번호 로그인
- [ ] 로그인 성공 시 JWT 토큰 발급
- [ ] 잘못된 비밀번호 5회 실패 시 15분 계정 잠금
- [ ] 로그인 상태 유지 (Remember Me)

## 인수 조건
- [ ] 올바른 이메일/비밀번호 → 200 + access_token
- [ ] 틀린 비밀번호 → 401 + "이메일 또는 비밀번호가 일치하지 않습니다"
- [ ] 5회 연속 실패 → 423 + "계정이 잠겼습니다. 15분 후 다시 시도하세요"
- [ ] Remember Me 체크 시 토큰 만료 30일

## 하지 않을 것
- 소셜 로그인 (Google/Kakao) — v2
- 2FA — v2
- 비밀번호 찾기 — v2
- 회원가입 — 별도 기능 (user-register)
